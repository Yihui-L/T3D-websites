# T3D Websites

T3D-lyh 程序手册、修改说明与验证记录的公开网站，无需登录。

| 目录 | 内容 | 网站 |
| --- | --- | --- |
| [Source-Code](Source-Code/README.md) | 程序手册、逐项修改、验证记录和 [T3D-lyh 源码快照](https://github.com/Yihui-L/T3D-websites/tree/main/Source-Code/T3D-lyh) | [程序手册](https://yihui-l.github.io/T3D-websites/Source-Code/) |

```text
T3D-websites/
├── Source-Code/
│   ├── T3D-lyh/
│   └── 程序手册、版本说明与网页资源
├── README.md
└── .nojekyll
```

源码快照的版本及许可见 [源码版本说明](Source-Code/SOURCE_VERSION.md)。官方 W7-X ReLU 对比及验证范围见 [程序手册](https://yihui-l.github.io/T3D-websites/Source-Code/#w7x)。

GitHub Pages 从 `gh-pages` 分支的根目录发布。更新网站时，将 `Source-Code/` 中的手册和网页资源同步到该分支，不复制源码快照。网站入口位于 `Source-Code/`，手册中的源码链接指向 `main` 分支的完整源码。
