`main` contains the public source snapshot and the editable static website
under `Source-Code/`. GitHub Pages serves a docs-only `gh-pages` branch;
the public source files are not duplicated into the Pages build.
The site documents cumulative changes relative to upstream T3D v0.1.0,
the official W7-X ReLU reference comparison, and validation limits.
