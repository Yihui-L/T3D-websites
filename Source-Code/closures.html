04 通量模型与并行调度¶

通量闭合、单位与后端¶

令各逆标长为：

κn=−∂ρln⁡n,κp=−∂ρln⁡p,κT=κp−κn\kappa_n=-\partial_\rho\ln n,\qquad \kappa_p=-\partial_\rho\ln p,\qquad \kappa_T=\kappa_p-\kappa_n

关闭噪声、暂不计经验背景项时，ReLU 模型输出的归一化热通量和粒子通量分别是：

q^=msgn⁡(κT)max⁡(∣κT∣−κc,0)b\widehat q=m\operatorname{sgn}(\kappa_T)\max(\lvert\kappa_T\rvert-\kappa_c,0)^b Γ^=sgn⁡(κn−κc)∣m(κn−κc)∣b\widehat\Gamma=\operatorname{sgn}(\kappa_n-\kappa_c)\lvert m(\kappa_n-\kappa_c)\rvert^b

各支路分别设定斜率和临界梯度，κc\kappa_c 可随 ρ\rho 线性变化。只有热支路有阈下关断；模型还可给粒子、热支路分别加上 DneonκnD_{\mathrm{neo}}n\kappa_n 和 DneopκpD_{\mathrm{neo}}p\kappa_p。这是归一化闭合，不是直接输入 SI 扩散系数，也不区分 ITG/TEM 等湍流模态。换成穿面粒子率和热功率时还需乘面几何及参考组分的局部 gyro-Bohm 因子。

  • 内置计算： ReLU 是参数化闭合；Chang–Hinton 是解析新经典近似，需适用几何；RR 是仅补到电子热流的 κT3\kappa_T^3 型模型；PowerBalance 由累计源反推平衡通量，独占使用，不是预测模型。
  • 外部计算： GX 与 GS2-QL 提供湍流/准线性输运；SFINCS、KNOSOS 与 NEO 提供新经典输运。T3D 给出各面当前态及梯度，按后端需要提交扰动计算；后端的局部响应进入隐式迭代。模板和可执行程序不是外部通量表；并行与缓存只改变调度方式，不应改变方程。
  • 文件给定： model = "Import" 读静态穿面 Γ（10²⁰ s⁻¹）或 Q（MW），用有符号线性插值到活动通量面，不外推；保持维度值，不给 Jacobian 增添虚假剖面导数。允许与非重复的在线分量相加，不应在回放总量后又叠加已含的模型。

I/O。 [[model]] 可重复声明兼容的加性闭合，用唯一标签区分输出；特定后端依赖其输入模板、所需平衡和运行环境。末帧不同步的外部诊断不标为有效。计算能力与实跑验证是两件事；见模型与外部源完整参数和逐项改动。

相对上游的改动¶

  • ReLU — 修复反向梯度的有符号通量；开启噪声时，同一步的基值与扰动共享抽样，不依赖全局随机种子，避免噪声直接污染有限差分。 源码 · 测试
  • Rechester–Rosenbluth — 在输运面使用同位置的参考归一化，补齐固定压强梯度下的密度扰动响应，不改原三次依赖。 源码 · 测试
  • GX 闭合 — ReLU 代理保留有符号的湍流能量交换 H 及梯度；先用完整物种集构造受约束梯度扰动，再筛选动力学组分。修复逐半径／角度的 GEQDSK 读取，并检查单样本与非有限输出。 源码 · 测试
  • GS2-QL — 修复 GEQDSK 初始化和逐面读取；修正纯静电、零流剪切极限、单 k_y 取样以及有符号的组分权重。准线性模型见 Giacomin 等（2025）。 源码 · 测试
  • SFINCS — 平衡文件拷贝完成后才启动求解；控制 MPI 秩与线程预算，检查 HDF5 完成标志、非线性收敛、形状及有限值，不把半写或失败输出当作有效通量。 源码 · 测试
  • GS2／NEO／KNOSOS 作业 — 用有界 CPU 调度和退出状态代替背景 shell 猜测；NEO 的输入解析器成功后才求解，KNOSOS 的径向输出必须齐全。 源码 · 测试
  • GX GPU 与 MPI 调度 — 本机按设备分组、每个任务按 GPU 数申请 MPI 秩；修正 Polaris 三卡分配，支持 Slurm／自定义启动器限流和可选的无进展报错。调度测试未用真实 GPU 或 Slurm。 源码 · 测试
  • 拒步、缓存与失败清理 — 每次运行使用独立目录，步／迭代／拒步重试有独立标识；检查子进程退出和全部预期输出，终止仍在运行的兄弟作业。GX 仅把已成功并与同一几何匹配的检查点作热启动，不复用旧通量。 源码 · 测试
  • GX 模板与 SFINCS 归一化 — GX 以 TOML 解析含引号、缩进和标点的模板；SFINCS 保留物理电荷符号，并与输运面使用的参考速度和通量单位一致。 源码 · 测试
  • NEO 与 KNOSOS 通量读回 — NEO 核对物种、径向输出形状和归一化；KNOSOS 按预测输出约定读取主离子、电子及杂质通量，检查半径和列数。 源码 · 测试
  • GX θ–ζ 图 — 拒绝掩蔽或非有限样本；仅在已采样点的凸包内插值，不把未覆盖区域推断为微小非零通量。 源码 · 测试
