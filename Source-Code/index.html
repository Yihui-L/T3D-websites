01 输运方程与数值求解

  • 变步长 BDF2 — 时间系数只使用已接受的历史步长；拒步恢复剖面并重算 θ 法所需的旧时刻输运项，不把试探状态写入历史。 源码 · 测试
  • 时间步控制 — 校验时间参数与重试上限；首步和增步遵守 dtau_max，SI 输入只转换有量纲的时间量，不转换缩步比或误差阈值；到达终止时刻时消除仅由舍入产生的额外小步。 源码
  • Newton 求解 — 以差分形式构造时间离散残差并直接求解修正量，降低大项相减误差；Jacobian 用同一离散残差、受约束剖面和后端梯度响应，包含内部碰撞及热源导数。显式推进跳过 Jacobian。 源码 · 测试
  • 收敛诊断 — 分开记录 Newton 更新量、时间离散残差、半离散稳态速率；稳态停止看实际输运速率，不因某次 Newton 更新很小而停。时间离散残差诊断不改变默认 Newton 接受阈值。 源码 · 测试
  • 共享界面与磁轴 — 相邻控制体共用同一个物理粒子／热通量；磁轴通量严格为零，指定外侧剖面节点不参与推进或活动壳积分。 源码 · 测试
  • 离散边界与终止 — 固定边界作为代数约束而非 BDF 外推；遇 stop 文件回滚未接受试探步；零时长或无演化变量时只写诊断，不强行推进。 源码 · 测试
  • 径向网格与紧致梯度 — 修复三点网格的节点／界面插值和边界导数。紧致差分用等价带状求解；保留浮点精度并拒绝非法网格、剖面和零差分步。未测量加速比。 源码 · 测试
  • 准中性与组分约束 — 一致处理从属物种、关联密度和温度剖面；支持显式选定准中性从属组分，拒绝重复组分、冲突约束和非正／非有限的密度或压强试探态。 源码 · 测试
  • 磁面准中性 — 密度插值发生正值回退时，各物种改用同一线性模板；同步约束基础和扰动的电荷梯度，输运模型、Jacobian 和输出使用同一套面梯度。 源码 · 测试
  • 剖面算术与 RMS — 剖面持有自己的数据，拒绝同长度但不同坐标的混算；Newton 的缩放 RMS 在极大、极小和空状态下不会意外溢出、下溢或崩溃。 源码 · 测试

02 平衡与几何

  • VMEC 体积导数 — 从半网格 Nyquist (0,0) 雅可比系数取 dV/ds，再按 ρ=√s 计算 dV/dρ；径向节点和输运面共用一致的面积／体积度量。 源码 · 测试
  • 磁面面积 — 周期角度采样不重复积分接缝；遇到不支持的非对称 wout 明确报错，不静默忽略非对称项。 源码
  • 基本几何与重标度 — 圆形基本几何的 A/a² 和 a|∇ρ| 使用一致无量纲定义，修正磁场默认与 VMEC LCFS 回退；径向线平均不再带长度单位，非法度量明确报错。 源码 · 测试
  • GEQDSK／Miller — 由实际能力选取唯一 GX 或 GS2-QL 几何提供者，不依赖自定义标签；GEQDSK 用 rminor 网格，逐面读入几何。Miller 必须启用兼容的导入，Boozer 预处理按后端能力执行。 源码 · 测试
  • DESC 平衡反馈 — 在导入 JAX 后端前选定 CPU／GPU；压强增减均可触发，分开保存候选平衡，仅接受收敛结果；按需要输出 VMEC 格式。当前只接受不改变演化壳层体积／参考小半径的更新；没有移动磁面输运或压缩功。 源码 · 测试
  • DESC 体积权重与 VMEC 输入 — DESC 直接插值原生 dV/dρ，再用面积一致地构造度量，明确要求 ρ=√s。VMEC 拒绝掩蔽输入并确保读取失败时关闭 NetCDF。 源码 · 测试
  • 几何积分与逐帧输出 — 修复节点和输运面的插值体积积分，逐帧保存度量；功率分解按所选帧取几何。Miller 重启只导入物理几何，不继承旧运行的模型和目录。 源码 · 测试

03 物理源项与反馈

  • 高斯源项归一化 — 对活动壳做体积积分；显式给定总源（包括零）按活动域归一化，不把固定外节点当作沉积单元；对域外中心的截断尾部给出警告，不把几乎无重叠误当作正常输入。 源码 · 测试
  • D–T 反应与 α 沉积 — 区分 α 出生功率、沉积热和聚变增益。关闭 α 热反馈或降低保留率不改变出生功率；独立 D/T 用两个 Maxwell 分布的相对温度。纯 H/e 不产生 D–T 功率。 源码 · 测试
  • 碰撞／辐射 — 用碰撞成对能量交换校验输运方程与源项导数；辐射模型已含轫致辐射时避免重复计入；关闭源项时清除残留诊断。 源码 · 测试
  • Zeff 与手动剖面 — 修复高斯／手动 Zeff 输入和混合电荷背景的杂质稀释，保持准中性；手工 n、T 表兼容 NumPy 2.x 并检查输入。 源码 · 测试
  • 辅助功率控制 — Q 控制使用出生聚变功率，把外部沉积计入增益分母，但仅调节可控的规定辅助功率；没有可调热源时不虚构反馈。 源码 · 测试
  • Sudo 与外侧边界 — 在初始化及已接受步之间应用密度反馈，单次通量、源项和残差计算使用同一个剖面。边界控制保持固定量、关联温度和准中性；发生跳变后下一步从一阶重启。Sudo 是经验反馈，不是额外演化方程。 源码 · 测试
  • PowerBalance — 独立的源平衡通量闭合在所有源项收集后计算，不能作为额外通量叠加到其他闭合。 源码 · 测试
  • BEAMS3D — 改用完整碰撞追踪；输入按 s、eV、m⁻³、kg 写入，输出用 √s 径向箱并汇总束线。修正 Fortran 起始下标、稀疏束线与同位素检查，分别控制粒子和能量源；可选独立 n,p 差分导数需要低标记噪声。目前离子沉积映射到主离子。 源码 · 测试
  • 剖面依赖与中性根 — 按依赖顺序处理 init_to / equal_to；若约束本身已使电荷恒为零，保留独立演化根；若单一密度根的比例与准中性冲突，给出明确错误。 源码 · 测试
  • 初始化与源项防护 — 自定义剖面组合平均值和边界值时保持固定边界；拒绝无物理意义的 Zeff 和非有限源项，清理外部源标签并校验 Q 控制范围。 源码 · 测试
  • BEAMS3D 一致性 — 不把仅在 T3D 中重标度的几何默认为真实束注入几何；新调用清除上一份输出，无独立未知量时不构造空 Jacobian。 源码 · 测试

04 通量模型与并行调度

  • ReLU — 修复反向梯度的有符号通量；开启噪声时，同一步的基值与扰动共享抽样，不依赖全局随机种子，避免噪声直接污染有限差分。 源码 · 测试
  • Rechester–Rosenbluth — 在输运面使用同位置的参考归一化，补齐固定压强梯度下的密度扰动响应，不改原三次依赖。 源码 · 测试
  • GX 闭合 — ReLU 代理保留有符号的湍流能量交换 H 及梯度；先用完整物种集构造受约束梯度扰动，再筛选动力学组分。修复逐半径／角度的 GEQDSK 读取，并检查单样本与非有限输出。 源码 · 测试
  • GS2-QL — 修复 GEQDSK 初始化和逐面读取；修正纯静电、零流剪切极限、单 k_y 取样以及有符号的组分权重。准线性模型见 Giacomin 等（2025）。 源码 · 测试
  • SFINCS — 平衡文件拷贝完成后才启动求解；控制 MPI 秩与线程预算，检查 HDF5 完成标志、非线性收敛、形状及有限值，不把半写或失败输出当作有效通量。 源码 · 测试
  • GS2／NEO／KNOSOS 作业 — 用有界 CPU 调度和退出状态代替背景 shell 猜测；NEO 的输入解析器成功后才求解，KNOSOS 的径向输出必须齐全。 源码 · 测试
  • GX GPU 与 MPI 调度 — 本机按设备分组、每个任务按 GPU 数申请 MPI 秩；修正 Polaris 三卡分配，支持 Slurm／自定义启动器限流和可选的无进展报错。调度测试未用真实 GPU 或 Slurm。 源码 · 测试
  • 拒步、缓存与失败清理 — 每次运行使用独立目录，步／迭代／拒步重试有独立标识；检查子进程退出和全部预期输出，终止仍在运行的兄弟作业。GX 仅把已成功并与同一几何匹配的检查点作热启动，不复用旧通量。 源码 · 测试
  • GX 模板与 SFINCS 归一化 — GX 以 TOML 解析含引号、缩进和标点的模板；SFINCS 保留物理电荷符号，并与输运面使用的参考速度和通量单位一致。 源码 · 测试
  • NEO 与 KNOSOS 通量读回 — NEO 核对物种、径向输出形状和归一化；KNOSOS 按预测输出约定读取主离子、电子及杂质通量，检查半径和列数。 源码 · 测试
  • GX θ–ζ 图 — 拒绝掩蔽或非有限样本；仅在已采样点的凸包内插值，不把未覆盖区域推断为微小非零通量。 源码 · 测试

05 输入、重启与诊断输出

  • 重启单位与网格 — 旧归一化量先还原到物理单位再用新参考量归一化，兼容旧 t_ref；拒绝坐标不匹配、缺测或掩蔽数据；变网格用壳层重叠映射，不声称跨几何体积守恒。 源码 · 测试
  • 文件通量导入 — 新增文件通量模型 Import：复用 [import] 与组分级 import/keys，读取每张磁面的有符号粒子率 (10^20/s) 与热功率 (MW)；在共享通量面线性插值，不外推，不折作体源。支持 ASCII 与已有 T3D 帧，及与 ReLU 相加；固定通量不影响 Newton Jacobian。 配置 · 源码 · 测试
  • 输入解析 — 保留实际 TOML／文件错误，不用错误的字符串回退覆盖原因；ASCII 多列源项求和，兼容 JETTO 时间键。 源码 · 测试
  • 检查点与输出路径 — 每 N 个接受步写检查点，NPY 和 NetCDF 写完才替换上一份，BP 单独路径；各格式不会共用同一个文件名。 源码 · 测试
  • 诊断对齐与单位 — 修正逐物种和离子汇总、粒子量和积分单位，分开输出 α 出生与沉积功率；记录几何文件、时间推进阶数、残差与诊断有效性。 源码 · 测试
  • 末帧与后处理 — 内部闭合在最终剖面重算；外部闭合如未同步则明确标 NaN，不为日志隐式启动求解。功率图按所选帧取通量，用已接受状态和已知阶数算时间导数，不猜旧文件的推进阶数。 源码 · 测试
  • TOML 写回与运行入口 — 字符串、嵌套表和数组可写回并重新读入。源码快照可用 python -m t3d 启动；输入扩展名错误返回非零且不创建输出日志。 源码 · 测试
  • TRANSP / JETTO 导入 — TRANSP 用质量和电荷辨认离子，不用电子密度补缺；处理单字符串与多源通道，校验径向网格和单位。JETTO 缺测值不再被当作物理数据。 源码 · 测试
  • 模型标签与失败诊断 — 单表和数组语法用同一诊断标签和计数，检查复合变量名碰撞；计算失败后不保留上一帧的有效诊断标记。 源码 · 测试

06 官方 W7-X ReLU

两版各接受 8 步并到达 0.37405577 s；中间接受时刻不同。只演化离子温度，密度、电子温度和外侧离子温度一致。源项来自规定电子剖面的碰撞能量交换。

使用各自终态剖面重算；最外输运面 ρ = 0.65882353。

  • 功率账口径 — 用实际接受步计算 BDF2 储能变化率；近轴体积权重与共享界面修正是主要差异。不能把离散功率残差降幅解读为实验精度提升。
  • 本轮：文件通量 — 195 项中 191 通过、4 跳过（GX、GS2、KNOSOS、真实 ADIOS2），其中新增 12 项；等效源对照、共享面守恒、符号、单位、NC/NPY 回放均通过。官方 W7-X ReLU 最新版与改动前 -lyh 的摘要和接受步历史逐字节相同。
  • 前一轮实跑 — 179 项通过、4 项跳过；最终一轮复查未发现新的可复现缺陷。SFINCS 在两处 W7-X 磁面上通过单进程 CPU 冒烟测试，DESC 固定平衡 ReLU 实跑通过；均未验证完整外部耦合或移动磁面输运。
  • 附加回归 — 动理学电子 W7-X ReLU 变体 7 步到终点并逐点保持准中性。D/T/C 变体的输入电荷份额为 1.05，程序明确拒绝原始输入。
  • 未实跑 — GX、GS2、BEAMS3D、KNOSOS、NEO、GPU/Slurm 和 ADIOS2。相关改动只验证了接口、合成数据或模拟调度。

这个算例不验证实验精度、外部求解器的物理收敛或并行扩展性。

07 复现与参考

  • 复现官方输入 — 在源码目录使用 t3d tests/regression/test-w7x-relu.in。无 ADIOS2 时，在另存的输入副本中关闭 output_adios2，不要修改官方输入。
  • 版本固定 — 源码树不含原始 Git 元数据，安装时如有版本识别问题可参照 可编辑文档的安装说明。源码身份以记录的 Git SHA 为准。
