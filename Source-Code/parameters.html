径向网格 [grid]

参数默认类型、单位或可选值含义与生效条件
N_radial10整数 ≥ 3剖面节点数；含最外 Dirichlet 节点，活动壳层和中点通量面各有 N−1 个。
rho_edge0.80 < ρ ≤ 1，无量纲外侧剖面节点坐标，不一定是 LCFS 或最后一个活动界面。
flux_label"torflux""torflux"、"rminor"分别表示归一化环向磁通平方根和几何小半径比 r/a；影响几何、文件、模型之间的径向映射。
rho_innerρ_edge/(2N−1)历史键，给值会警告当前不能手动配置；内侧剖面节点由均匀网格决定，磁轴零通量独立施加。

时间推进 [time]

默认时间单位是参考时间 t_ref。[time].alpha 是时间离散权重，与剖面参数 alpha 无关。

参数默认类型、单位或可选值含义与生效条件
dtau0.5有限正数，s 或归一化时间初始步长；先限制到 dtau_max，最后一步可裁剪到 t_max。
dtau_max10.0有限正数，s 或归一化时间步长上限。
dtau_adjust2.0有限实数 > 1，无量纲拒步后的除数；合格接受步的增长倍率另固定为 2。
dtau_increase_thresholdnewton_threshold/4非负有限实数，无量纲接受步的 RMS 足够小才允许增长步长。
N_steps1000整数 ≥ 0最大接受步数；0 时不推进。
t_max1000非负有限实数，s 或归一化时间终止时间；0 时不推进，仍可写诊断。
alpha1有限实数 [0,1]θ 隐式权重。0 显式，0 < α < 1 为 θ 方法；1 首步后向 Euler，之后用接受历史做变步长 BDF2。
max_newton_iter4整数 ≥ 1每个尝试步允许的 Newton 迭代次数。
newton_threshold0.02非负有限实数，无量纲常规 Newton 接受阈值（活动节点的相对剖面更新量 RMS；隐式残差另记诊断，不参与此阈值）。
newton_tolerance0.1非负有限实数，无量纲达到迭代上限时允许的较宽接受阈值。
rms_converged1e−16非负有限实数，归一化空间变化率阈值按各活动节点的相对空间平衡残差判断是否提前稳态终止；0 禁用，不等于 Newton 容差。
max_timestep_retries20整数 ≥ 0同一已接受时刻还能重试的次数上限。
use_SIfalse布尔为 true 时 dtau、dtau_max、t_max 为秒；只换算这三个量，倍率、RMS 阈值不换算。

平衡几何 [geometry]

VMEC、DESC 需 torflux；Miller 和 GEQDSK 需 rminor。GEQDSK 还需恰好一个 GX 或 GS2‑QL 几何提供者。输入的几何数据必须与其他径向数据的磁通标签一致。

参数默认类型、单位或可选值含义与生效条件
geo_option"basic""basic"、"vmec"、"desc"、"geqdsk"、"miller"圆形近似、VMEC wout、DESC 平衡、GEQDSK 或由读入文件提供的 Miller 几何。
geo_file空字符串文件路径VMEC 用 wout NetCDF；DESC 用原生平衡文件（通常 .h5）或 VMEC .nc；GEQDSK 用平衡文件，由后端读。
AspectRatio0（basic 回退 4）正实数 R/a，无量纲basic 可设；VMEC、DESC、GEQDSK 由平衡确定；Miller 从输入数据确定。
iota230.75正实数，无量纲用于 ISS04 等的 ρ≈2/3 旋转变换；相关读入平衡可覆盖此值。
importfalse布尔Miller 必须启用，且共享 [import] 必须提供兼容几何；不用于替代 VMEC/ DESC 的 geo_file。
evolve_equilibriumfalse布尔；启用只支持 desc允许按输运压强触发重算。不能把固定几何的回归理解成已验证移动磁面守恒。
update_equilibrium未设布尔，历史别名仅在 [geometry] 下等价于上项。两者同时出现且冲突会报错；[physics].update_equilibrium 不被读，官方旧算例保留该无效键。
desc_pressure_delta_threshold1.25启用时有限实数 ≥ 1最大双向压强比超过该阈值才更新平衡。
desc_pressure_delta2启用时有限实数 ≥ 1更新触发后，小于此双向压强比走扰动，大变化走完整求解。
desc_use_vmec_format按文件后缀推断布尔；保留未设可自动推断控制 DESC 重算的输出格式及依赖 VMEC 格式的耦合路径，不改变输入读取器；.nc 时默认 true，原生格式默认 false。
desc_device"auto""auto"、"cpu"、"gpu"在导入计算后端前选择 JAX 设备；auto 优先可用 GPU。
geo_outputs"geo/"目录路径DESC 更新的平衡和日志目录，各次求解在隔离子目录。
use_beta_prime_alphafalse布尔GS2-QL 用读入的 Miller β′_α 作为几何输入。
beta_prime_constfalse布尔用初始或导入的 β′，而不是每次随剖面更新（现行 GS2-QL 分支）。
force_beta_prime_speciesfalse布尔与 beta_prime_const 配合，沿用支持的 Miller 重启/几何所提供的 β′；不是所有几何均有该数据。
compute_surface_areastrue布尔，兼容键当前版本读取但无后续控制分支，不会关闭通量面面积计算。
overwritefalse布尔，兼容键当前 Geometry 只保存该键；不控制求解器后端各自的 overwrite。

尺寸与磁场缩放 [rescale]

参数默认类型、单位或可选值含义与生效条件
L_mult1推荐有限正实数，无量纲线性尺度倍率；0 为历史输入，回退 1。体积随尺度的立方变化（适用的几何分支）。
L_def空格（自动）"minor"、"major" 或省略basic/VMEC 选择小/大半径为标度。VMEC 指定模式时须给对应的 a_minor 或 R_major；DESC、GEQDSK 走 a_minor 优先逻辑。
a_minor0（未覆盖）正实数，m小半径标度，最终乘 L_mult；basic 若强制 minor 却为 0 回退 1 m。
R_major0（未覆盖）正实数，m大半径标度，乘 L_mult；basic 走大半径而未给值时回退 4 m；VMEC 的 major 模式须给正值。
B_mult1推荐有限正实数，无量纲磁场倍率；0 在常用几何分支回退 1。
B_def空格（自动）"LCFS"、"volavgB"、"vmecB0" 或省略basic/VMEC 的磁场规格。DESC、GEQDSK 主要使用 Ba 覆盖加倍率。
Ba0（未覆盖）正实数，T边缘/参考磁场输入；VMEC 的 LCFS 模式可覆盖读入值，basic 默认 1 T。
volavgB0（未覆盖）正实数，TB_def=volavgB 时令体平均磁场达到给定标度；basic 将其作为 Ba。
vmecB00（未覆盖）正实数，TB_def=vmecB0 时令轴上磁场达到给定标度；不是把 Btor 直接设为 B0。

组分 [[species]]

参数默认类型、单位或可选值含义与生效条件
type"deuterium"已知：electron、hydrogen、deuterium、tritium、helium、boron、carbon、oxygen、neon、krypton、tungsten，或带 mass 和 Z 的自定义离子名不同组分名称必须唯一，须含电子和至少一个离子。
tag内置 e、H、D、T、He、B、C、O、Ne、Kr、W 等，否则用 type字符串日志、输出变量和文件导入缺省字段后缀。
mass内置组分表正有限实数，m_p质量乘质子质量；自定义离子显式提供。
Z内置组分表电子 −1、离子有限正数，e电荷数，参与准中性、碰撞与有效电荷。
adiabaticfalse布尔，至多一个物种标记绝热响应并关闭该组分独立的密度和温度推进；仅固定状态不等于开启它。
bulkfalse（无标记则首个离子）布尔，至多一个且不能为电子主离子选择。
use_as_reference随 bulk（无显式选择则首个离子）布尔，至多一个决定湍流/gyro-Bohm 归一化参考组分。
impurity是否给定该组分的 Zeff 目标布尔，至多一个离子将该物种标为初始化杂质，参与准中性从属组分选择。
Zeff未设实数，满足 Z_eff,background < 目标 < Z_impurity初始化指定有效电荷并按电荷比例稀释其余离子；不同于 [physics].Zeff 的制动辐射系数设置。
qneut_speciesfalse（自动挑选从属根）布尔；至多一个，不可再给 density.equal_to此组分的密度由逐面准中性计算，而不是独立推进；当现有链接已恒等满足准中性时不必消去自由度。
rel_step0.5非负有限实数通量闭合的相对梯度探测步幅。
abs_step0.5非负有限实数通量闭合的绝对梯度探测下限；有效探测步 max(rel_step×基准梯度绝对值, abs_step) 必须非零。
density、temperature空表内联表，见下分别设置粒子密度和温度的初值/边界/演化自由度。
aux_particle_source、aux_power_source空表内联表，见下分别设置辅助加料和加热的体源。
density_source、pressure_source未设历史别名与对应新键同现时旧表覆盖新表；建议只使用新键。
density_relu_flux、pressure_relu_flux空表内联表，见下ReLU 的组分级粒子/热通量参数；后者虽名 pressure，阈值作用在温度梯度。
particle_flux、heat_flux空表内联表，见下为 Import 模型绑定指定的穿面粒子率和热功率。

状态剖面 density、temperature

状态单位：n 用 10²⁰ m⁻³，T 用 keV。表内键在 density 和 temperature 中各自使用；组分间链接在初始化与推进中分开处理。

参数默认类型、单位或可选值含义与生效条件
evolvetrue布尔是否作为独立未知量。准中性、绝热或 equal_to 从属物种可移除此自由度。
equal_to未设"electron" 或 "0.5 * electron"；系数有限且 > 0全程保持与目标组分同类剖面的比例，不独立推进；拒绝循环。
init_to未设同 equal_to只在初始化按比例设置，之后按本组分 evolve 状态处理；同一剖面不可同时设 equal_to。
shape"parabolic""parabolic"、"gaussian"、"exponential"、"manual"、"custom"内置初始剖面表达；启用 import 时文件读入优先。
core密度 4；温度 8对应状态单位parabolic 默认核心幅值。
edge未设（parabolic 回退：密度 0.5、温度 2）对应状态单位外侧约束；读文件时若显式指定会覆盖最外径向点。指数及自定义分支具有各自的重标定逻辑。
sep未设对应状态单位parabolic 给非零 core 和 sep 时以 ρ=1 为参考边界；低于 lineavg/volavg 优先级。
lineavg未设对应状态单位parabolic/custom 目标算术节点平均，实现中为离散节点平均，不是合成诊断弦积分。
volavg未设对应状态单位parabolic/custom 目标体平均；parabolic 在没有有效 lineavg 时使用。
alpha1有限实数；平滑正剖面通常取正parabolic 的外幂 α。
alpha12有限实数；平滑正剖面通常取正parabolic 的径向内幂；形状为 (1−x^alpha1)^alpha。
height0对应状态单位gaussian 峰值；须配合有效 integrated 或非零正幅值，保证初值正。
integrated未设状态单位 × m³gaussian 体积分归一化目标；非零时优先于 height。
width0.1正实数，ρ 的单位gaussian 标准差。
center0有限实数，ρ 的单位gaussian 中心。
coefs[0,0,0,0]数字数组，使用前四项；不足补 0exponential 的 c₀…c₃：c₀ exp(−c₁ρ²−c₂ρ⁴−c₃ρ⁶)；c₀ 用状态单位。
importfalse布尔从共享 [import] 读初始状态；是否演化另由 evolve 决定。
key未设变量/列名字符串（单数）文件字段；ASCII/T3D 默认 n_<tag> 或 T_<tag>；JETTO 必须显式指定。
profstr未设两行数字字符串，以分号隔开半径和值；数值可逗号或空白分隔manual 用 PCHIP；横坐标是 ρ/ρ_edge，严格递增并覆盖节点，剖面值有限且正。
func未设含 def init(rho): ... 的多行 Python 字符串custom 参数；输入代码由本进程执行，仅使用可信 TOML；函数返回与网格长度匹配的值或标量。

辅助源 aux_particle_source、aux_power_source

静态导入是一次性快照；没有文件时序强迫。高斯归一化使用演化域，不把固定边界节点当活动壳层。

参数默认类型、单位或可选值含义与生效条件
shape"gaussian"目前仅 "gaussian"不导入文件时的径向形状；代码求活动壳层平均。
height0有限实数；粒子 10²⁰ m⁻³ s⁻¹、热 MW m⁻³规定体源峰值；integrated 未设才使用，允许有符号源或汇。
integrated未设有限实数；粒子 10²⁰ s⁻¹、热 MW以活动体积分为目标；显式 0 会覆盖 height 并给零源。分布太窄或大部分在域外会警告或拒绝。
width0.1正有限实数，ρ 的单位非零高斯的标准差。
center0有限实数，ρ 的单位非零高斯的中心。
importfalse布尔使用共享 [import] 的体源列/场，替代高斯，不会关闭 collisions 等独立物理源；只进对应演化方程。
keys未设字符串或字符串数组，取决于读者ASCII、TRANSP、JETTO 可对多项求和；T3D 重启指定一个源诊断字段，读取后转换归一化，默认 Sn_aux_<tag> 或 Sp_aux_<tag>。

bremsstrahlungfalse布尔单独启用基于 Z_eff 的轫致辐射。

轫致辐射使用的 [physics].Zeff

数值 Zeff = 1.5 直接设常量。若用表选择解析形式，不应把默认的 0 理解为物理推荐值。

参数默认类型、单位或可选值含义与生效条件

importfalse布尔从当前实现支持的 TRANSP U-file 读取 Z_eff；ASCII、T3D 或 JETTO 读者不提供该专用入口。
key未设变量名字符串TRANSP 默认依次用 ZEFFR / ZEFF。
shape"parabolic""parabolic"、"gaussian"、"exponential"、"manual"选择静态剖面，无 custom 模式。
core0实数；Z_eff 无量纲parabolic 核心幅值，应给物理合理的正值。
edge0实数；Z_eff 无量纲parabolic 外侧参数。
sep0实数；Z_eff 无量纲非零时给 ρ=1 参考值，见 parabolic 分支。
volavg未设实数；Z_eff 无量纲parabolic 的指定体平均。

通量模型 [[model]] 与外部源 [[source]]

模型选择与通用约定

以下参数由 d5ac1fe 直接读取；类型或范围写的是可用输入，不能视为已验证所有后端。省略表示 TOML 中不写该键，不是写入 null。外部程序自己的原生输入关键字不属于 T3D 参数表；模板可保留它们，T3D 为每次计算覆盖几何、组分、梯度和必需的运行/输出项。后端工作目录采用本次运行隔离，裸路径相对于启动目录。

参数类型／可选值默认值含义与约束
model注册名或注明别名"GX"选择通量模型。见下表；全局可写 [model] 或多个 [[model]]。没有该表时默认尝试 GX。多个通量模型通常叠加；PowerBalance 例外。
label非空字符串，不含 /；同一运行中各模型的输出标签唯一各模型表所示用于分项通量输出，例如 Q_ReLU_MW_H。模型和独立源项各自有自己的标签空间。

ReLU — 参数化通量

粒子支使用 [species.density_relu_flux] 的零通量逆标长；热支使用 [species.pressure_relu_flux] 的温度逆标长阈值。阈值径向变化由组分表指定；模型级 noise 与组分表中的保留字段 noise_frac 不同。

参数类型／可选值默认值含义与约束
D_neo有限实数；物理扩散应非负0.0经验背景项强度：粒子分支加 n κ_n D_neo，热分支加 p κ_p D_neo；不是自动 DKES/SFINCS 新经典系数。

noise有限实数 [0,1]0乘法噪声幅度；按物理步、组分、通量面、通道抽样。同一接受步的 Newton、扰动和重试共用该步抽样。
random_seed非负整数10随机种子。
label输出标签"ReLU"模型输出名称；模型名也接受 relu。

接受 ASCII 空白分列文本或 T3D 快照中的物理诊断；不读任意 TRANSP/JETTO 通量或随时间推进的序列。通量面输入是整个磁面的有符号粒子率（10²⁰ s⁻¹）或热功率（MW）；不是热流密度，也不是已经归一化的 gyro-Bohm 通量。不是源项，不贡献剖面 Jacobian。单独一个数据列可按组分标记回落到 Gam_SI20_<tag> 或 Q_MW_<tag>。文件中不得有非零轴上穿面量，禁止径向外推；在读入时选定一帧后固定。

BEAMS3D — 外部中性束源项

几何需 torflux 且有 VMEC 格式 wout*.nc；不能只改变 T3D 的尺寸或磁场参考值而让外部程序继续使用原始磁平衡，否则会报错。HDF5 后处理按束求和，再插值到状态剖面节点，而不是求输运通量。支持接口/合成数据验证，不宣称完成真实 BEAMS3D 工况验证。
