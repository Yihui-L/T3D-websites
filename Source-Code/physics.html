03 物理源项与反馈¶

源与汇的物理模型¶

离子升温、电子降温可以来自同一个成对换热项。温度按能量计：

SE,coll,s=32ns∑uνsuE(Tu−Ts)S_{E,\mathrm{coll},s}=\frac{3}{2}n_s\sum_u\nu^E_{su}(T_u-T_s)

物理组分全部演化时，成对交换总和应为零；固定某个温度时，它相当于规定热库，不应声称该简化系统独立闭合总热量。径向热流不是碰撞体热源。

  • 辅助粒子源与辅助能量源可规定高斯形状 Aexp⁡ ⁣[−(ρ−ρ0)2/(2σ2)]A\exp\!\bigl[-(\rho-\rho_0)^2/(2\sigma^2)\bigr]。若指定 integrated，用活动壳的 ∑jΔVjSj\sum_j\Delta V_j S_j 反求幅值；否则使用 height。也可导入离线沉积或使用 BEAMS3D 在线计算。
  • D–T α 出生功率密度是 EαnDnT⟨σv⟩(Trel)E_\alpha n_{\mathrm D} n_{\mathrm T}\langle\sigma v\rangle(T_{\mathrm{rel}})，Eα≈3.5 MeVE_\alpha\approx3.5\,\mathrm{MeV}；两 Maxwellian 温度独立时，Trel=(mTTD+mDTT)/(mD+mT)T_{\mathrm{rel}}=(m_{\mathrm T}T_{\mathrm D}+m_{\mathrm D}T_{\mathrm T})/(m_{\mathrm D}+m_{\mathrm T})。沉积功率等于出生功率乘 alpha_efficiency（且需开启热反馈），再按电子/离子份额分配；聚变总出生功率为 α 出生功率约 5.03 倍。该通道不等同于求解燃耗、灰积累或快粒子输运。
  • 杂质辐射是电子能量汇，按 ne∑iniLi(Te)n_e\sum_i n_i L_i(T_e) 组装；包含谱线、复合和轫致辐射的模型开启时，不重复加独立的轫致辐射 ∝Zeffne2Te\propto Z_{\mathrm{eff}}n_e^2\sqrt{T_e}。可另计通量后端提供的湍流组分间能量交换。
  • 可选功率或边界反馈在已接受步之间更新；Sudo 是经验密度控制，不是额外演化方程。辅助功率反馈也不读取时变文件。

I/O。 [physics] 开关物理源，[[species]].aux_particle_source / aux_power_source 给规定源，[[source]] 选择外部沉积后端，[time_dependence] 控制反馈。正的热源表示向该组分加热，诊断以分项和总量分别输出；活动壳功率积分排除固定边界节点。完整源参数和配置。

相对上游的改动¶

  • 高斯源项归一化 — 对活动壳做体积积分；显式给定总源（包括零）按活动域归一化，不把固定外节点当作沉积单元；对域外中心的截断尾部给出警告，不把几乎无重叠误当作正常输入。 源码 · 测试
  • D–T 反应与 α 沉积 — 区分 α 出生功率、沉积热和聚变增益。关闭 α 热反馈或降低保留率不改变出生功率；独立 D/T 用两个 Maxwell 分布的相对温度。纯 H/e 不产生 D–T 功率。 源码 · 测试
  • 碰撞／辐射 — 用碰撞成对能量交换校验输运方程与源项导数；辐射模型已含轫致辐射时避免重复计入；关闭源项时清除残留诊断。 源码 · 测试
  • Zeff 与手动剖面 — 修复高斯／手动 Zeff 输入和混合电荷背景的杂质稀释，保持准中性；手工 n、T 表兼容 NumPy 2.x 并检查输入。 源码 · 测试
  • 辅助功率控制 — Q 控制使用出生聚变功率，把外部沉积计入增益分母，但仅调节可控的规定辅助功率；没有可调热源时不虚构反馈。 源码 · 测试
  • Sudo 与外侧边界 — 在初始化及已接受步之间应用密度反馈，单次通量、源项和残差计算使用同一个剖面。边界控制保持固定量、关联温度和准中性；发生跳变后下一步从一阶重启。Sudo 是经验反馈，不是额外演化方程。 源码 · 测试
  • PowerBalance — 独立的源平衡通量闭合在所有源项收集后计算，不能作为额外通量叠加到其他闭合。 源码 · 测试
  • BEAMS3D — 改用完整碰撞追踪；输入按 s、eV、m⁻³、kg 写入，输出用 √s 径向箱并汇总束线。修正 Fortran 起始下标、稀疏束线与同位素检查，分别控制粒子和能量源；可选独立 n,p 差分导数需要低标记噪声。目前离子沉积映射到主离子。 源码 · 测试
  • 剖面依赖与中性根 — 按依赖顺序处理 init_to / equal_to；若约束本身已使电荷恒为零，保留独立演化根；若单一密度根的比例与准中性冲突，给出明确错误。 源码 · 测试
  • 初始化与源项防护 — 自定义剖面组合平均值和边界值时保持固定边界；拒绝无物理意义的 Zeff 和非有限源项，清理外部源标签并校验 Q 控制范围。 源码 · 测试
  • BEAMS3D 一致性 — 不把仅在 T3D 中重标度的几何默认为真实束注入几何；新调用清除上一份输出，无独立未知量时不构造空 Jacobian。 源码 · 测试
