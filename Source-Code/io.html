05 输入、重启与诊断输出¶

输入 → 计算 → 输出¶

  1. 输入：主文件是扩展名为 .in 的 TOML。设置网格、时间、组分与约束、平衡、通量和源模型。文件路径通常相对进程工作目录。不要把模型名、后端模板和径向数据文件当成同一类参数。
  2. 计算：初始化剖面与定值导入；每次试探在同一几何上求源和输运，组装离散残差，接受或回退。默认外部文件只选择一个径向切片；frame 是初始化选择，不是随模拟时钟推进的索引。
  3. 输出：.out 是终端日志；默认快照 *.log.npy（Python pickle，只从可信来源读）；*.nc 为可选 NetCDF4（默认关）；*.bp/ 为 ADIOS2（默认开，可显式关闭写出）。接受步检查点频率由 [log].n_write 决定；各输出形态由同一输出 stem 派生而不会共用文件名。
数据所在网格与物理单位输入／输出中的名字
组分密度、温度、压强节点；10²⁰ m⁻³、keV、10²⁰ keV m⁻³density、temperature；输出 n_*、T_*、p_*
辅助粒子源、体热源壳层节点；10²⁰ m⁻³ s⁻¹、MW/m³aux_particle_source、aux_power_source；Sn_*、Sp_* 输出是归一化本地值，乘对应 Sn_ref_SI20、P_ref_MWm3 转为物理单位
穿面的粒子率、热功率界面；10²⁰ s⁻¹、MWparticle_flux、heat_flux；Gam_SI20_*、Q_MW_* 已有物理单位。不能用 pflux_*、qflux_*（gyro-Bohm）代替
时间及有效性时间帧；t 以 t_ref 归一化t_step_idx、t_iter_idx、t_diagnostics_valid；查已接受态时选 t_iter_idx=0 并核对有效标志

导入格式。 ASCII columns 是空白分列文本（# 注释；divide_by 按列换单位）；节点初态插值、辅助源区间平均、通量面线性插值是不同操作。T3D .nc/.npy/.bp 用 frame 取一帧；旧源单位先还原再归一化，通量只读有量纲诊断。若从 T3D 快照恢复 Miller 几何，需保存同一径向网格的 Miller 几何对象的 .npy。TRANSP u-file 与 JETTO NetCDF 另可选时间切片用于剖面/源导入，不走通用通量表分支。运行期时变文件读取尚未实现。

复现与定位。 从对应源码根目录按 t3d case.in -l case.out 或已安装环境中的 python -m t3d case.in 启动；主输入不能脱离其相对文件路径。详细输入参数表包括各组默认值、允许值、单位、后端环境和兼容性；用于实验性改模前先核对目标后端的验证边界。

相对上游的改动¶

  • 重启单位与网格 — 旧归一化量先还原到物理单位再用新参考量归一化，兼容旧 t_ref；拒绝坐标不匹配、缺测或掩蔽数据；变网格用壳层重叠映射，不声称跨几何体积守恒。 源码 · 测试
  • 文件通量导入 — 新增文件通量模型 Import：复用 [import] 与组分级 import/keys，读取每张磁面的有符号粒子率 (10^20/s) 与热功率 (MW)；在共享通量面线性插值，不外推，不折作体源。支持 ASCII 与已有 T3D 帧，及与 ReLU 相加；固定通量不影响 Newton Jacobian。 配置 · 源码 · 测试
  • 输入解析 — 保留实际 TOML／文件错误，不用错误的字符串回退覆盖原因；ASCII 多列源项求和，兼容 JETTO 时间键。 源码 · 测试
  • 检查点与输出路径 — 每 N 个接受步写检查点，NPY 和 NetCDF 写完才替换上一份，BP 单独路径；各格式不会共用同一个文件名。 源码 · 测试
  • 诊断对齐与单位 — 修正逐物种和离子汇总、粒子量和积分单位，分开输出 α 出生与沉积功率；记录几何文件、时间推进阶数、残差与诊断有效性。 源码 · 测试
  • 末帧与后处理 — 内部闭合在最终剖面重算；外部闭合如未同步则明确标 NaN，不为日志隐式启动求解。功率图按所选帧取通量，用已接受状态和已知阶数算时间导数，不猜旧文件的推进阶数。 源码 · 测试
  • TOML 写回与运行入口 — 字符串、嵌套表和数组可写回并重新读入。源码快照可用 python -m t3d 启动；输入扩展名错误返回非零且不创建输出日志。 源码 · 测试
  • TRANSP / JETTO 导入 — TRANSP 用质量和电荷辨认离子，不用电子密度补缺；处理单字符串与多源通道，校验径向网格和单位。JETTO 缺测值不再被当作物理数据。 源码 · 测试
  • 模型标签与失败诊断 — 单表和数组语法用同一诊断标签和计数，检查复合变量名碰撞；计算失败后不保留上一帧的有效诊断标记。 源码 · 测试
